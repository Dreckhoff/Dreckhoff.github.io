Magical Unemployment

A roguelike deckbuilder about being unemployed, applying for jobs, and surviving strange evening card duels.

You spend the day sending applications and waiting for replies. At night, you play card battles to recover enough mental energy to keep going. Wins bring money, booster packs grow your collection, and the run ends either with a job offer or by defeating Die Personalabteilung.

What kind of game is it?

A small Python/Pygame project mixing a meta-layer with card combat.

Day cycle

Mornings are for applications. Replies arrive later, usually as rejections, but one job offer is a possible win condition.

Deckbuilder loop

Evening duels earn money. Money buys booster packs. Booster packs expand the collection used to build a 20-card deck.

Playable status

The current repository README describes Phase 2 + 3 as playable, with GUI, meta-layer, save/load, and 25 YAML-defined cards.

How to play locally

Clone the repository, install the Python dependencies, and start the Pygame version.

Recommended terminal setup

After cloning the repository and installing the dependencies once, macOS users can start the game later by double-clicking Magical Unemployment.command. 

git clone https://github.com/Dreckhoff/magical_unemployment.git
cd magical_unemployment
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python play_gui.py

Other useful commands

You can always start the graphical version from the terminal with python play_gui.py. The older terminal menu is still available via python play.py. 

pytest
python play.py

Requirements

The project declares Python 3.11 or newer. Its listed dependencies are pygame-ce, pyyaml, and pytest.
